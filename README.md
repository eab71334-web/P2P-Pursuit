# Co-Driver Rally (Godot 4.3) — لعبة رالي تعاونية على LAN

لاعبان في سيارة واحدة:

- **DRIVER (السائق):** يشوف الطريق فقط ويسوق.
- **CO-DRIVER (المساعد):** يشوف خريطة المرحلة وملاحظات المنعطفات (Chill left / Yikes right / Oh no…) ويقرأها للسائق بصوته.

الهدف: إنهاء المرحلة بأسرع وقت للحصول على ميدالية Gold / Silver / Bronze.

## اللعب على LAN

1. الجميع على نفس الشبكة (Wi-Fi واحد).
2. واحد يضغط **HOST LAN GAME** ويختار عدد اللاعبين (2–4).
3. الباقي تظهر لهم اللعبة في القائمة (أو يكتبون الـ IP الظاهر عند المضيف) ويضغطون **JOIN**.
4. **اللعبة تبدأ تلقائياً عندما يكتمل العدد** (عدّاد 3-2-1 ثم GO).
5. الأدوار: أول لاعب (المضيف) = سائق، الثاني = مساعد، الباقي = ركاب (يشوفون الخريطة).

`Solo practice` للتجربة وحدك (تظهر لك الخريطة أيضاً).

المنافذ: UDP 24565 (اللعب) و UDP 24566 (اكتشاف الألعاب). إذا ما ظهرت اللعبة في القائمة اكتب الـ IP يدوياً.

## البناء عبر GitHub

1. ارفع محتوى هذا المجلد كما هو إلى مستودع GitHub (الملفات في الجذر: `project.godot` وغيره).
2. تبويب **Actions** ← **Build game** ← **Run workflow** (أو أي push يبنيها تلقائياً).
3. حمّل الناتج من **Artifacts**: `windows` و `linux` و `android` (APK تجريبي).

> بناء Android في الـ workflow محاولة بأفضل جهد (`continue-on-error`) ولم يُجرَّب على GitHub بعد؛ بناءا Windows/Linux هما الأساس.
> لـ iOS: انسخ مجلدي `scripts/` و `scenes/` مع `project.godot` و `icon.svg` إلى مستودعك الذي فيه workflow الـ iOS، وتأكد أن المشروع الرئيسي يشير إلى `res://scenes/main.tscn`.

## الجديد: سباق الفرق + التفاعل داخل السيارة

**TEAM RACE:** من القائمة اختر عدد الفرق (2 إلى 4). كل فريق = سيارة + لاعبان (سائق + حامل الخريطة). تبدأ اللعبة تلقائياً عند اكتمال كل اللاعبين، والترتيب حسب الدخول (الأول سائق والثاني مساعد للفريق A وهكذا).

| الإجراء | كمبيوتر | جوال |
|---|---|---|
| الالتفات لرؤية صاحبك | سحب بالزر الأيمن، أو اضغط V | اسحب بإصبعك على الشاشة |
| ضرب صاحبك (اليد اليمنى) | F أو Space | PUNCH |
| المساعد: أشر يسار / مستقيم / يمين / قف | 1 / 2 / 3 / 4 (اضغط نفس الزر ثانية لإرجاع اليد) | الأزرار أسفل الشاشة |
| المساعد: إشارة في الطريق (عمود ضوء وسهم على الطريق الصحيح) | G | SIGNAL |
| إخفاء/إظهار الخريطة | M | MAP |

- من يُضرب يشعر باهتزاز (جوال أو يد تحكم) وتهتز الشاشة، وإذا كان السائق يرتجف المقود لحظة.
- **الطرق المسدودة:** في المرحلة تفرعات (Fork) أحد فرعيها مغلق بحاجز "ROAD CLOSED". الخريطة (عند المساعد فقط) تظهرها بالأحمر، وإذا دخل السائق طريقاً مسدوداً يظهر للمساعد تنبيه. السائق لا يرى الخريطة، فالمساعد يحذره بيده وصوته.
- **العوائق:** صخور، جذوع أشجار، وحدبات قفز (Big bump) تظهر في ملاحظات الخريطة.
- كل لاعب له شخصية مكعبة: السائق يمسك المقود، والمساعد يمسك السبورة بيده اليسرى ويشير بيده اليمنى.

## الجديد: سباق الجبل + سائق شبه أعمى + أيباد

- **مولّد المراحل (بدون نت):** عند بداية كل لعبة "مخرج مراحل" داخل اللعبة يولّد عدة مراحل ويختار الأمتع (طرق مسدودة كثيرة، منعطفات صعبة، منحدرات، حواف جبل، مخاطر نادرة) — كل مرة حلبة جديدة واسم جديد. هو خوارزمية على الجهاز وليس نموذج ذكاء اصطناعي حقيقي.
- **الثيمات:** جبل (الأكثر احتمالاً) / ثلج / خريف.
- **الجبل:** طلوع ونزول، **حواف بلا حواجز (Cliff edge)** — لو سقطت السيارة تعود للطريق مع **+5 ثواني**؛ **جليد (Ice)** تنزلق عليه السيارة؛ **انهيار صخور (Rockfall)** يسد جزءاً من الطريق؛ **Over crest** قمة لا ترى بعدها الطريق.
- **السائق الأعمى (خيار في القائمة، مفعّل افتراضياً):** عالم أسود، طريق خافت جداً بضوء السيارة فقط، ونص إشارة المساعد مخفي — لازم يتبع **يد المساعد** (الكابينة فيها ضوء خافت) وصوته وعمود الإشارة (G).
- **الأيباد:** الخريطة صارت جهاز أيباد في حضن المساعد داخل اللعبة. لازم ينزّل رأسه ليشوفه (اسحب للأسفل)، وزر **M / MAP** يقرّب على الأيباد. السائق يشوف المساعد ينظر للأسفل.

## الجديد: واجهة احترافية + عربي + لعب جماعي 2-6

- **الشاشة أفقية دائماً** (landscape): مضبوطة في `project.godot` (كانت "حسب الحساس" فتنقلب عمودي) + تعديل `Info.plist` في workflow الآيفون.
- **قائمة متحركة:** خلفية جبال وطريق وسيارة تتحرك، بطاقات الأوضاع تكبر عند اللمس، وانتقالات ناعمة.
- **شاشة انتظار متحركة:** عدّاد دائري، نقاط متحركة، شريط تعبئة، وخانة لكل لاعب تظهر باسمه ولون فريقه لحظة دخوله.
- **شرح اللعب قبل السباق:** صور متحركة لدورك (سائق / مساعد / متسابق)، زر **تخطي**، وخيار "لا تظهر مرة أخرى". السباق ما يبدأ إلا بعد ما الكل يخلص أو يتخطى.
- **العربية:** زر اللغة أعلى القائمة (الافتراضي عربي). الخط DejaVu Sans مرفق في `fonts/` لأنه يدعم العربي.
- **كل واحد لنفسه (2-6 لاعبين):** لكل لاعب سيارته وخريطته، أول واحد يعبر خط النهاية يفوز.

## الجديد: أصوات + محرك يدخّن ويحترق

- **الأصوات:** كلها مولّدة بالكود (`tools/make_sounds.py` → مجلد `audio/`): صوت محرك يتغير مع السرعة والتروس (ناقل حركة)، شفط الهواء، ضجيج الطريق والحصى، انزلاق الإطارات، اصطدامات، حريق، طفاية، مقابض وأبواب، وعدّاد البداية.
- **الضرر:** الاصطدام أو القيادة بسرعة قصوى لفترة تسخّن المحرك: دخان (≥40) يضعف القوة، ثم **نار** (≥80). النار تكبر ولو تأخرت 45 ثانية ينفجر المحرك (+25 ثانية عقوبة).
- **الإصلاح:** أوقف السيارة ← **E** تسحب مقبض الكبوت من داخل السيارة ← **E** تنزل ← ترفع الكبوت (E أو اسحب الشاشة للأعلى) ← امسك **Q** (أو زر RSH) وصوّب الطفاية على النار ← افتح غطاء المحرك بيدك الثانية (E) لأن فيه نار مخبّأة تحته ← أطفئها ← انتظر يبرد ← **E** تغلق وترجع. في سباق الفرق أي واحد من الاثنين ينزل ويصلح.

## الجديد: غرفة اللاعبين + كراج + ورشة + شخصية + مستويات + انفجار

> **ما تغيّر:** الطريق وطريقة تصليح السيارة بقيتا **كما كانتا بالضبط**. الإضافة الوحيدة في الحريق: لو انتهى وقت الحريق (45 ثانية، أو أكثر مع ترقية التبريد) يصير **انفجار**.

**الغرفة (Room)**
- بعد ما تنشئ لعبة (فرق / تعاوني / كل واحد لنفسه) تفتح غرفة. كل لاعب يقدر يدخل **الكراج / الورشة** من داخل الغرفة ويغيّر سيارته وشكله، ثم يضغط **جاهز**.
- لما يكتمل العدد ويصير الكل جاهز يطلع **عدّاد 5 ثواني** ثم تبدأ اللعبة. أي واحد يلغي "جاهز" أو يخرج يوقف العدّاد.
- بعد السباق: **إعادة المباراة** (ترجع للغرفة وأنت جاهز) أو **الرجوع للغرفة**. صاحب الغرفة (الذي يشغّل الفيزياء) أزرار الخروج عنده تتفعّل لما يخلص الكل.
- زر **رجوع** داخل الغرفة يطلع رسالة: «هل أنت متأكد أنك تريد الخروج من الغرفة؟» ثم **تأكيد** يرجعك للقائمة الرئيسية. (لو خرج صاحب الغرفة تنقفل على الكل.)

**الواجهة الرئيسية (Hub):** شريط علوي (المستوى + XP + العملات + الجواهر) وتبويبات: العب / الكراج / الورشة / الشخصية / المتجر / المهام / الصناديق. عرض ثلاثي الأبعاد دوّار للسيارة والشخصية (اسحب لتدوّرها).

**السيارات (6 موديلات مكعبات بشكل سباق):** Rally Hatch RX (مجانية) – Dune Buggy – Muscle GT – Trail 4x4 – Apex Coupe – Phantom Hyper. كل واحدة بقوة/سرعة/ثبات/متانة مختلفة وتُشترى بالعملات حسب المستوى. تعديل الشكل: **الطلاء** (مات، لؤلؤي، ذهبي، كروم)، **الخطوط**، **الجنوط**، **إضاءة سفلية**.

**الورشة (ترقيات لكل سيارة، 5 مستويات):** المحرك (قوة+سرعة) – الإطارات (ثبات) – الدرع (الاصطدام يضر أقل) – التبريد (حرارة أقل + الحريق يتأخر قبل الانفجار) – الطفاية (تطفئ أسرع). هذه الترقيات تؤثر فعلاً على فيزياء السيارة في السباق.

**الشخصية:** البشرة، القبعة (خوذة/كاب/طاقية/سماعة/بندانا/كاوبوي/قبعة رسمية/تاج ذهبي)، النظارة، التيشيرت (جاكيت، هودي، بدلة البطل الذهبية)، السروال، الحذاء، و**حركات (Emotes)** — اضغط **T** أو زر EMOTE في السباق. الندرة: عادي / نادر / ملحمي / **أسطوري**.

**التقدم:** مستويات وXP، جوائز عند كل مستوى، **مهام يومية** (3 جديدة كل يوم + صندوق ذهبي لو أنهيتها كلها)، مكافأة دخول يومية (7 أيام)، **صناديق** (برونزي/فضي/ذهبي) بنسب ندرة، **عروض يومية** بخصم 30%، ومكافآت بعد كل سباق (عملات + XP + صندوق للفائز). الحفظ على الجهاز في `user://profile.json`.

**الانفجار:** لو ما أُطفئ الحريق: إنذار صوتي في آخر 10 ثواني ثم تنفجر السيارة في منتصف الطريق: كرة نار وموجة صدمة ودخان وقطع تتطاير، تطير السيارة في الهواء وتنقلب، ومن كان واقفاً أمامها يُقذف للخلف. بعد ~4.5 ثانية ترجع للطريق (+25 ثانية عقوبة).

**أفكار مستوحاة من ألعاب السباق (CSR Racing وغيرها):** كراج وسيارات بندرة متدرجة، ترقيات أداء، مهام يومية، صناديق جوائز، تخصيص مظهر. (للفكرة العامة فقط؛ لم يُنسخ أي محتوى أو أصول.)

> **غير مختبر:** البناء على الجوال/GitHub لم يُجرَّب، والأصوات لم أسمعها فعلياً، وتوازن الأسعار والمكافآت تقديري ويحتاج لعب حقيقي.

## تحديث 5 — ناقل الحركة (القير)
- لكل سيارة قير مختلف: يدوي H (هاتشباك/بقي/سييرا 5 سرعات، موستانغ 6)، أوتوماتيك P R N D (بيك أب/تشارجر/كوبيه/M4)، تتابعي (GT3)، أزرار R N D (هايبر).
- كل سيارة لها مقبض قير بشكله (كرة كروم، مسدس، مفتاح إلكتروني …).
- القير يُحسب من السرعة والاتجاه: وقوف = N (أو P في الأوتوماتيك)، رجوع = R، تقدّم = D أو رقم السرعة.
- عند التغيير: اليد اليمنى تترك المقود، تذهب للمقبض، تنقله لموضعه، ثم ترجع للمقود. العداد يعرض الحرف/الرقم.
- اختبار: `CARS=hatch,m4 tools/run.sh gear`

- العداد خلف المقود كما في السيارة الحقيقية في كل السيارات، بدون المكعبات الخارجية حوله.
- المرآة الأمامية مثبتة بسقف السيارة فوق السائق (قاعدة + ساق). المقعد أخفض قليلًا، وأذرع السائق أنحف حتى لا تغطي العداد.
- الكراج: صفحة كاملة، السيارة في الوسط، شريط السيارات ممتد بعرض الشاشة بصور الغلاف، وقدرات السيارة فوق الشريط.
- زر «تعديل» يفتح صفحة التعديل: أقسام بالأسفل (الطلاء: لون/خطوط/ملصقات/إضاءة، التعديلات، العجلات، المحرك) وشريط خيارات بعرض الشاشة. الورشة القديمة أُلغيت.
- ملصقات جديدة على الأبواب (أرقام وشارات RS/GT/V8/X).
- اختبار: `tools/run.sh garage` و `tools/run.sh modify`

## تحديث 7
- اختيار طريقة التحكم قبل أول سباق (على اللمس): زرين يمين/يسار، دومان، أو دومان 360. يظهر مرة واحدة فقط، ويتغير من الإعدادات (قسم «التحكم»).
- الدومان على الشاشة يلف باللمس ويرجع للوسط لما تفلته. دومان 360 يلف دورة كاملة لكل جهة، ودومان السيارة يلف معه، ويد السائق تبرمه يدًا فوق يد.
- قسم جديد «الشكل» في صفحة التعديل: جناح خلفي، مقدمة، غطاء محرك، جوانب/عتبات. لكل سيارة خياراتها (مثلاً الهايبر وGT3 عندهما جناح مزدوج وطقم عريض، والبقي والبيك أب عندهما حديد حماية أمامي).
- اختبار: `TOUCH=1 tools/run.sh steer` و `CAR=gt3 tools/run.sh body`

## التحديث 8 — تعديلات خاصة بكل سيارة
- **المحرك**: لكل سيارة محركها الحقيقي (مثلاً M4 = 3.0 توين تيربو I6، GT3 = فلات-6 تنفّس طبيعي، Hyper = W16 رباعي التيربو) وخمس مراحل تطوير بأسماء حقيقية.
- **القطع**: أسماء التيربو/العادم/الإيرو/التعليق/الحماية تختلف لكل سيارة، والقطع غير الموجودة بالواقع تختفي (GT3 بدون تيربو، البوغي بدون إيرو).
- **العجلات**: 9 تصاميم (5 أذرع، شبكي، متعدد، تيربين، أوف رود، كلاسيك، قفل مركزي، حديد) وكل سيارة لها تصميمها الأصلي وخيارات تناسبها، تظهر بالمجسم وبالبطاقات.
- **الخطوط**: لكل سيارة تخطيط مختلف (ماسل: خطان عريضان فوق الغطاء والسقف، GT3: شريط جانبي سفلي، M4: خطوط رفيعة، بيك أب: شريط جانبي...).
- الاختبار: لقطات سطح مكتب فقط، لا اختبار على هاتف حقيقي.
